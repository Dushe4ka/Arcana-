# Arcana — мобильное приложение

Написано на Expo (React Native) + TypeScript, экраны собраны через expo-router.
Экраны: вход/регистрация, каталог историй, карточка истории с главами (в т.ч.
платными за энергию), экран чтения (фон, спрайты персонажей, диалоги, мысли,
выбор с ценой в монетах/кристаллах), профиль с кошельком и ежедневной наградой.

## Запуск для разработки (в Expo Go, без сборки APK)

```bash
cd apps/mobile
cp .env.example .env   # укажите адрес вашего запущенного backend (apps/api)
npx expo start
```

Отсканируйте QR-код приложением **Expo Go** на телефоне (Android/iOS) — это
самый быстрый способ проверить приложение без сборки APK. Учтите: если backend
и телефон не в одной Wi-Fi сети, замените `localhost` в `.env` на LAN-адрес
компьютера.

## Сборка настоящего APK-файла (EAS Build)

Собрать `.apk`, который можно установить на любой Android-телефон без Expo Go,
можно только через облачный сервис Expo (EAS Build) — в этой изолированной
среде разработки нет доступа к серверам expo.dev, поэтому саму команду сборки
нужно запустить со своего компьютера:

```bash
npm install -g eas-cli
cd apps/mobile
eas login              # войти в аккаунт expo.dev (создайте бесплатно на expo.dev)
eas build:configure    # один раз, привязывает проект к вашему аккаунту
eas build --platform android --profile preview
```

Сборка займёт 5–15 минут в облаке Expo, после чего в терминале и на
expo.dev появится прямая ссылка на скачивание `.apk`.

**Важно:** приложению нужен доступ к работающему backend (`apps/api`). Для
локального теста в Expo Go можно использовать адрес своего компьютера, но для
собранного APK backend должен быть развёрнут на публично доступном адресе —
иначе телефон не сможет достучаться до "localhost" (это будет означать сам
телефон, а не ваш компьютер). Впишите настоящий адрес backend в
`eas.json` → `build.preview.env.EXPO_PUBLIC_API_URL` перед сборкой.
