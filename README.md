# Arcana

Мобильное приложение интерактивных визуальных новелл (жанр «Клуб Романтики»), с собственным
брендингом, историями и персонажами. Контент (истории, диалоги, выборы, ветвления) хранится
в базе данных и публикуется через админ-панель — без релиза новой версии приложения.

## Структура репозитория

```
apps/
  api/      Backend на Python (FastAPI) — единый API для мобильного приложения и админ-панели
  admin/    Next.js веб-панель для сценаристов (создание историй, глав, диалогов)
  mobile/   React Native (Expo) приложение — iOS и Android из одного кода
packages/
  shared/   Общие TypeScript-типы и Zod-схемы валидации для admin/mobile (backend на Python
            использует свои Pydantic-схемы с той же формой данных)
```

`apps/api` — самостоятельный Python-проект (свой virtualenv, requirements.txt), не часть
pnpm workspace. `apps/admin`, `apps/mobile` и `packages/shared` — pnpm workspace (Turborepo).

Архитектура:

```
Mobile App  ─┐
             ├─▶ Backend API (Python/FastAPI) ─▶ PostgreSQL
Admin Panel ─┘
```

Backend — на Python, потому что так попросил владелец продукта. Мобильное приложение и
админ-панель остаются на TypeScript/React, потому что для кроссплатформенной мобильной
разработки и богатого визуального редактора историй у Python нет зрелых инструментов
такого уровня — они обращаются к Python-серверу через обычный HTTP API.

## Backend (apps/api)

Модульный монолит на FastAPI + SQLAlchemy (async) + Alembic + PostgreSQL.

Ключевые модули:
- **auth** — регистрация, вход, JWT (access + refresh с ротацией)
- **content** (stories/characters/scenes) — CRUD для историй/сезонов/глав/персонажей/переменных/сцен
  (только для ролей WRITER/EDITOR/ADMIN)
- **play** — «движок чтения»: выдаёт текущую сцену игроку, обрабатывает выборы, автоматически
  проходит узлы условий/эффектов, ведёт сохранения
- **wallet** — внутренняя валюта (мягкая/твёрдая), энергия/билеты на открытие глав, ежедневные
  награды

### Локальный запуск

1. Поднимите PostgreSQL.
2. Создайте виртуальное окружение и установите зависимости:
   ```
   cd apps/api
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements-dev.txt
   ```
3. Скопируйте `.env.example` в `.env` и подставьте свои значения.
4. Примените миграции и заполните демо-данными:
   ```
   alembic upgrade head
   python seed.py
   ```
5. Запустите сервер в режиме разработки:
   ```
   uvicorn app.main:app --reload --port 4000
   ```
   API будет доступен на `http://localhost:4000/api`, автодокументация (Swagger) — на
   `http://localhost:4000/docs`.

После сидирования доступен админ-аккаунт: `admin@arcana.app` / `ChangeMe123!`
(обязательно смените пароль перед выходом в продакшн).

Проверка качества кода: `ruff check app seed.py` и `ruff format app seed.py`.

### Демо-история

Сид создаёт полностью играбельную короткую историю «Маска и Слово» (1 сезон, 2 главы,
3 персонажа, переменные характеристик/отношений, платный и условный выбор) — чтобы можно
было проверить всю цепочку админка → API → чтение истории.

## Модель контента

- `Story` → `Season` → `Chapter` → `SceneNode` (диалог / выбор / условие / эффект / конец)
- `SceneNode` типа `CHOICE` имеет связанные `ChoiceOption` — сама структура графа сцен
  спроектирована так, чтобы её было удобно визуализировать как узлы/связи в будущем
  визуальном редакторе админ-панели.
- Тексты хранятся как `{ ru: "...", en: "..." }` (легко добавить новые языки).
- Характеристики игрока и отношения с персонажами — это `VariableDefinition` (переменная,
  опционально привязанная к персонажу) + `PlayerVariableValue` (значение конкретного игрока).
- Условия (`ConditionGroup`) и эффекты (`EffectList`) — JSON-структуры, которые пишет
  сценарист через админку, а движок (`apps/api/app/services/play_service.py` +
  `apps/api/app/engine/condition_engine.py`) интерпретирует во время чтения.

## Статус разработки

Backend (Python/FastAPI) и модель данных реализованы и протестированы (регистрация, каталог,
чтение главы, выборы, ветвление по условиям, энергия/билеты, валюта, ежедневная награда).
Далее: админ-панель (Next.js) и мобильное приложение (Expo).
