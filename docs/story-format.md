# Формат документа истории ARCANA

Историю можно написать в обычном документе (Word, Google Docs → .docx, либо .txt / .md) и
загрузить в админ-панель: **История → «Загрузить документ истории»**. Реплики, выборы,
условия и главы разложатся сами. После загрузки всё можно править вручную в редакторе и
на графе.

Загрузка всегда идёт в два шага: «Проверить» показывает, что будет создано и какие строки
непонятны; «Импортировать» создаёт главы как **черновики**. Ничего не публикуется само.

Правило одно: **одна строка — один элемент**.

## Структура документа

| Что пишем | Что получится |
|---|---|
| `# Сезон 1` | начало сезона |
| `## Глава 1: Бал` (или `## Серия 1: Бал`) | начало главы с названием |

В Word можно не ставить решётки: оформите строку «Сезон 1» стилем **Заголовок 1**, а
«Глава 1: Бал» — стилем **Заголовок 2**.

Всё, что стоит до первого заголовка главы, в игру не попадает (туда можно писать заметки).

## Текст

| Что пишем | Что получится |
|---|---|
| `Вечер. Зал наполнялся гостями.` | текст рассказчика |
| `Адриан: Добрый вечер.` | реплика персонажа (имя до двоеточия) |
| `Лия (мысли): Он смотрит на меня.` | мысли персонажа |
| `// заметка для команды` | комментарий, в игру не попадает |

При первой загрузке админка спросит про каждое имя: это существующий персонаж, новый
персонаж или просто текст рассказчика.

## Выбор

```
? Как ответить?
- Улыбнуться -> тепло
- Отшутиться -> шутка
- Пригласить на танец [карты 5] -> танец
```

- Строка с `?` — вопрос. Под ней — варианты, каждый с `-` в начале.
- После `->` — **метка**, куда ведёт вариант.
- `[карты 5]` или `[зёрна 20]` — платный вариант.

## Метки и переходы

```
== тепло ==
Адриан: Я рад, что вы пришли.
-> финал

== финал ==
=== КОНЕЦ ===
```

- `== имя ==` — метка: место, куда можно перейти. Метки действуют внутри своей главы.
- `-> имя` — перейти к метке после предыдущей строки.
- Если после реплики нет `->`, история идёт на следующую строку.

## Характеристики, отношения и флаги

Изменить значение — в фигурных скобках:

```
{смелость +1}
{доверие(Адриан) +2; ключ = да}
```

- `+` и `-` прибавляют и вычитают, `=` задаёт значение.
- В круглых скобках — персонаж, если это отношение с ним: `доверие(Адриан)`.
- `да` / `нет` — флаг, число — характеристика, слово в кавычках — текст.
- Характеристики, которых ещё нет в истории, будут созданы при загрузке (админка покажет
  их список заранее).

Изменение можно повесить прямо на вариант выбора:

```
- Улыбнуться {доверие(Адриан) +2} -> тепло
```

## Условия

Вариант, который виден только при условии:

```
- Взять его за руку [если смелость >= 1] -> рука
```

Развилка без выбора игрока:

```
[если доверие(Адриан) >= 2] -> признание | иначе -> холод
```

- Если `| иначе -> …` не написать, при невыполненном условии история идёт на следующую строку.
- Сравнения: `>=`, `<=`, `>`, `<`, `=`, `!=`. Несколько условий — через `и` или `;`.
- Значения сохраняются между главами и сезонами: флаг, поставленный в первой главе, можно
  проверить в десятой.

## Финал главы

```
=== КОНЕЦ ===
=== КОНЕЦ: Рассвет вдвоём ===
```

Вторая форма даёт финалу название — он попадёт в коллекцию игрока. Каждая ветка главы
должна заканчиваться финалом или переходом.

## Режиссура

Ремарка ставится **перед** репликой, к которой относится. Фон, музыка, атмосфера и
иллюстрация сохраняются в следующих репликах, пока вы их не смените.

| Ремарка | Значения |
|---|---|
| `@фон: ссылка` | ссылка на загруженную картинку |
| `@музыка: ссылка` / `@музыка: стоп` | включить трек / плавно остановить |
| `@звук: ссылка` | звук, прозвучит один раз |
| `@cg: ссылка` / `@cg: убрать` | иллюстрация на весь экран |
| `@атмосфера:` | дождь, снег, туман, пыль, искры, лепестки, убрать |
| `@эффект:` | тряска, вспышка, сердце, расфокус |
| `@переход:` | затемнение, растворение, сдвиг |

Ссылки на файлы берутся в админке после загрузки картинки или трека. Их можно не
указывать в документе и расставить позже в редакторе.

## Пример целиком

```
# Сезон 1

## Глава 1: Бал
@фон: https://…/hall.jpg
@музыка: https://…/theme.mp3
Вечер. Зал наполнялся гостями.
Лия (мысли): Он смотрит на меня.
Адриан: Добрый вечер.

? Как ответить?
- Улыбнуться {доверие(Адриан) +2} -> дальше
- Отшутиться {смелость +1} -> дальше
- Пригласить на танец [карты 5] {доверие(Адриан) +3} -> танец

== танец ==
@cg: https://…/dance.jpg
Они закружились в танце.
@cg: убрать
-> дальше

== дальше ==
{была на балу = да}
[если доверие(Адриан) >= 2] -> тепло | иначе -> холод

== тепло ==
Адриан: Я рад, что вы пришли.
=== КОНЕЦ: Тёплый вечер ===

== холод ==
Адриан: Что ж. Доброй ночи.
=== КОНЕЦ: Холодный вечер ===

## Глава 2: Сад
[если была на балу = да] -> помнит
Лия (мысли): Я здесь впервые.
=== КОНЕЦ ===

== помнит ==
Лия (мысли): Я помню этот сад.
=== КОНЕЦ ===
```

## Что проверяется при загрузке

- вариант без `->`, переход на несуществующую метку, глава, которая обрывается без финала;
- непонятные изменения и условия;
- глава, в которой уже есть сцены, и опубликованная глава — в них импорт не идёт, чтобы
  ничего не затереть.

После загрузки откройте в главе вкладку **«Проверка сюжета»** и граф истории: там видны
тупики, недостижимые сцены и то, какие решения на что влияют.
